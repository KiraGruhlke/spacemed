Session 4 Reflection: Algorithm design

Date: April 09, 2026 Course: SpaceMed – U5-EC3 Digital Literacy In session 4 we started to extract and analyze the first data set. We were introduced to quarto to make documents reproducable and sharable with other platforms and in other formats (html, pdf). We added metadata to a “raw” cell in the notebook—such as setting the document class to “article”. We converted lists into arrays using the numpy-function, since arrays allow for more complex operations (square, etc.). We learned to navigate through the data to make sure we are not making any mistakes, since in arrays all data needs to be in exactly the same format, sometimes you need to slice, etc. Finally we plotted our first data set, looked at a subset, detected peaks, stored them in an array. Then we calculated heart rate and plotted it.
