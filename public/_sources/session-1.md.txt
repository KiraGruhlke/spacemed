# Session 1 Reflection: Getting Started
*Date: March 12, 2026
Course: SpaceMed – U5-EC3 Digital Literacy*
In the first class we learned to navigate in the Shell environment. The picture we used for that was a tree. As I picture it, it is a way to start a folder structure with documents in different folders and navigating from one to another, not by clicking with the mouse as in a user interface but by typing various commands, to see where you currently are, to jump forward, backwards, create a new folder or document or delete folders and documents. The most important difference to me is that no waste bin exists, why commands, especially linked to deleting, must be handled carefully. We started to look into the “vocabulary” of these commands.
Additionally, we talked about GitLab, which I understand is a tool to save all versions of a shared document. I still need to look into how this is linked with the Jupyter environment and how it is working.
