In session 7 we packaged the files from last session into a script, that we can execute in the command line.
By adding entry points to the setup.cfg file, we made it so we could run our tools (like sm_plot_heart) directly from the terminal. We then learned how to professionalize our code by running Linters (flake8) on it. This checks for coding consstency and "style", so it is easily readable for everyone. We used pytest to test individual functions, such as a division function and our peak-finding logic, even checking how the code handles errors like dividing by zero. We then lookind into ways of documentation, since "future me" will definitely forget how this code works. Timewise we didn't manage to setup Sphinx to automatically generate clean HTML documentation from our docstrings and markdown files. Finally, we touched (only in short theory) on how to share our work with the world properly (Zenodo to get a DOI, add a CITATION.cff).
