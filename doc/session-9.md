In session 9 we learned about High Performance Computing (HPC) and parallel programming/ computing. We started by defining HPC as the techniques used for massive computations that just won't fit on a standard computer - either because they take too long or need too much memory. This is why you break them down into a lot of smaller problems, that you can run parallel and then need to synchronize. We learned about the hardware as well as the componenets of a digital computer and how they work together on the example of the Charité HPC. We then got into practice with Slurm, the cluster workload manager. It allocates specific hardware resources (like CPUs or GPUs) to a user for a set amount of time. It provides the framework needed to start, execute, and monitor computing jobs. We logged into into it, to get an overview of our own jobs and automatically ask for nodes, storage space and GPU, etc. We then learned how to start a job (sbatch) and check if it is done/track it (squeue) and get the results on the example of phr.sh. In the end we created a template for an array of jobs to run multiple jobs at once.
